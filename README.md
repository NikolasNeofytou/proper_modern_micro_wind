# Modern Microwind - Circuit Design Tool

A modern, user-friendly web-based circuit design and layout tool inspired by Microwind, built with enhanced UX features including snap-to-grid, extensive keyboard shortcuts, and beautiful modern graphics.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Features

### 🎯 Enhanced Precision
- **Snap-to-Grid System**: Configurable grid with adjustable spacing (0.5mm to 5.0mm)
- **Visual Grid Display**: Toggle-able grid overlay for precise alignment
- **Object Snapping**: Automatically align components to grid points
- **Real-time Cursor Coordinates**: Always know your exact position

### ⌨️ Comprehensive Keyboard Shortcuts
- **F7**: Toggle Grid visibility
- **F9**: Toggle Snap to Grid
- **Ctrl+Z / Ctrl+Y**: Undo / Redo
- **Ctrl+C / Ctrl+V**: Copy / Paste
- **Ctrl+D**: Toggle Dark Mode
- **Ctrl+A**: Select All
- **Del**: Delete selected
- **V**: Select Tool
- **R**: Rectangle Tool
- **W**: Wire Tool
- **C**: Component Tool
- **Space**: Pan mode (hold)
- **Arrow Keys**: Navigate canvas
- **Ctrl+Plus/Minus**: Zoom in/out
- **F**: Fit to screen

### 🎨 Modern Graphics & UI
- **Dark Mode Support**: Eye-friendly dark theme with proper contrast ratios
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **High-DPI Support**: Crisp graphics on retina displays
- **Smooth Animations**: Fluid transitions and interactions
- **Modern Color Scheme**: Professional color palette with accent colors

### 🛠️ Design Tools
- **Select Tool**: Click to select and manipulate shapes
- **Rectangle Tool**: Draw rectangular components
- **Wire Tool**: Connect components with wires
- **Component Tool**: Place circuit components
- **Zoom Controls**: Smooth zoom in/out with mouse wheel or keyboard
- **Pan Tool**: Navigate large designs easily

### 💾 Workflow Features
- **Unlimited Undo/Redo**: Never lose your work
- **Copy/Paste**: Duplicate designs quickly
- **Selection System**: Easy object selection and manipulation
- **Status Bar**: Real-time feedback on tools and settings
- **Properties Panel**: Quick access to settings and shortcuts

## 🚀 Getting Started

### Quick Start

1. Simply open `index.html` in a modern web browser (Chrome, Firefox, Safari, or Edge)
2. Start designing immediately - no installation required!

### Basic Usage

1. **Select a Tool**: Click a tool button in the toolbar or use keyboard shortcuts
2. **Draw on Canvas**: Click and drag to create shapes
3. **Adjust Grid**: Use the grid size dropdown to change spacing
4. **Toggle Features**: Use F7 for grid and F9 for snap
5. **Zoom**: Use Ctrl+Plus/Minus or mouse wheel to zoom
6. **Pan**: Hold Space and drag, or use arrow keys

## 📚 User Guide

### Understanding the Interface

#### Header Bar
- Application title and version
- Dark mode toggle
- Settings button

#### Toolbar
- **Tool Group 1**: Selection and drawing tools
- **Tool Group 2**: Undo/Redo operations
- **Tool Group 3**: Grid and snap controls with size selector
- **Tool Group 4**: Zoom controls

#### Main Canvas
- Large drawing area with real-time cursor coordinates
- Grid overlay (when enabled)
- Selected shapes highlighted in orange

#### Properties Panel
- Grid settings
- Selection information
- Keyboard shortcuts reference

#### Status Bar
- Current status message
- Zoom level indicator
- Grid and snap status

### Drawing Workflows

#### Creating a Simple Circuit Layout

1. Enable snap-to-grid (F9) for precise alignment
2. Select Rectangle tool (R) to draw component boundaries
3. Use Wire tool (W) to connect components
4. Place Component symbols (C) at connection points
5. Use Select tool (V) to adjust positions

#### Best Practices

- **Use Grid Alignment**: Keep grid and snap enabled for professional layouts
- **Adjust Grid Size**: Use finer grids (0.5mm) for detailed work, coarser (5mm) for layout
- **Leverage Shortcuts**: Learn keyboard shortcuts for faster workflow
- **Zoom Appropriately**: Zoom in for detail work, zoom out for overview
- **Save Frequently**: Use browser bookmarks or export features (coming soon)
