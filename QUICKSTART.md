# Quick Start Guide - Modern Microwind

## Getting Started in 30 Seconds

1. **Open the Application**
   - Simply open `index.html` in your web browser
   - Works on Chrome, Firefox, Safari, or Edge

2. **Draw Your First Shape**
   - Press `R` for Rectangle tool (or click the Rectangle button)
   - Click and drag on the canvas to draw
   - The shape snaps to the grid automatically!

3. **Try Keyboard Shortcuts**
   - Press `F7` to toggle grid visibility
   - Press `F9` to toggle snap on/off
   - Press `Ctrl+D` to toggle dark mode
   - Press `V` to return to Select tool

## 5-Minute Tutorial

### Basic Circuit Layout

1. **Enable Grid and Snap** (default on)
   - Grid helps align components precisely
   - Snap makes positioning effortless

2. **Draw Component Blocks**
   - Press `R` for Rectangle tool
   - Draw two rectangular blocks (these represent circuit components)
   - They automatically snap to grid points

3. **Connect with Wires**
   - Press `W` for Wire tool
   - Click and drag to create connections
   - Wires snap to endpoints

4. **Add Component Symbols**
   - Press `C` for Component tool
   - Click to place component symbols
   - These appear as orange boxes with internal symbols

5. **Select and Modify**
   - Press `V` for Select tool
   - Click any shape to select it (turns orange)
   - Press `Del` to delete selected shape

### Navigation Tips

- **Zoom In/Out**: `Ctrl+Plus` / `Ctrl+Minus` or mouse wheel
- **Pan**: Hold `Space` and drag, or use arrow keys
- **Fit to Screen**: Press `F`

### Workflow Shortcuts

- **Undo/Redo**: `Ctrl+Z` / `Ctrl+Y`
- **Copy/Paste**: `Ctrl+C` / `Ctrl+V`
- **Delete**: `Del` key

## Common Workflows

### Design a Simple Circuit

```
1. Draw two rectangles (R key) for logic gates
2. Connect them with wires (W key)
3. Add component symbols (C key) at key points
4. Adjust grid size if needed (dropdown in toolbar)
5. Toggle grid off (F7) to see clean result
```

### Precision Work

```
1. Set grid to 0.5mm for fine detail
2. Enable snap (F9) for exact alignment
3. Use zoom (Ctrl+Plus) to see details
4. Use arrow keys for small adjustments
```

### Quick Exploration

```
1. Try dark mode (Ctrl+D) - easier on eyes
2. Draw various shapes to test tools
3. Use Undo (Ctrl+Z) freely - unlimited undo!
4. Press F to fit everything on screen
```

## Troubleshooting

**Q: Shapes aren't aligning properly**
- Make sure Snap is enabled (F9 or click Snap button)
- Check if it's active (button should be highlighted)

**Q: Can't see the grid**
- Press F7 to toggle grid visibility
- Grid button should be highlighted when visible

**Q: Zoom is too sensitive**
- Use keyboard: Ctrl+Plus/Minus for controlled zoom
- Use mouse wheel for smooth zooming

**Q: Lost a shape after drawing**
- Shapes might be off-screen - press F to fit all
- Check if you're in dark mode - shapes may blend in

## Tips & Tricks

1. **Use Grid Sizes Wisely**
   - 0.5mm - Detail work
   - 1.0mm - Standard work (default)
   - 2.0mm - Quick layouts
   - 5.0mm - Large designs

2. **Combine Tools**
   - Draw rectangles for component boundaries
   - Add wires for connections
   - Place component symbols at junctions

3. **Efficient Workflow**
   - Learn 3-5 keyboard shortcuts you use most
   - Keep snap on for precision
   - Use undo liberally - it's unlimited!
   - Zoom in for detail, zoom out for overview

4. **Visual Clarity**
   - Use dark mode for reduced eye strain
   - Toggle grid off when presenting
   - Colors: Blue=rectangles, Green=wires, Orange=components
